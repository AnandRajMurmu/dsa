# 🧠 Data Structures & Algorithms

A personal repository for learning and practicing **Data Structures and Algorithms using Python**.

The focus is on developing strong problem-solving skills, understanding core data structures and algorithms, and learning how to progress from straightforward solutions to optimized approaches.

> **Understand → Solve → Analyze → Optimize → Practice**

## 📚 Learning Path

This repository follows a structured approach to learning and practicing DSA:

### Primary Roadmap

**[Striver's A2Z DSA Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z)**

> Used for learning concepts and progressing through DSA topics systematically.

### Problem Practice

**[LeetCode](https://leetcode.com/)**

> Used for additional practice, reinforcing concepts, and improving problem-solving skills.


### 🗺️ Topics

The repository will progressively cover:

- 🧩 DSA Fundamentals
- 📦 Arrays and Strings
- 🔀 Sorting and Binary Search
- 🔗 Linked Lists
- 🔁 Recursion and Backtracking
- 🔢 Bit Manipulation
- 📚 Stacks and Queues
- 🪟 Two Pointers and Sliding Window
- ⛰️ Heaps and Priority Queues
- 🎯 Greedy Algorithms
- 🌳 Binary Trees and Binary Search Trees
- 🕸️ Graphs
- 🧮 Dynamic Programming
- 🌱 Tries
- 🚀 Advanced problem-solving patterns

### 💡 Problem-Solving Approach

For each problem:

1. Understand the problem and constraints
2. Develop a brute-force or naive approach
3. Analyze time and space complexity
4. Identify opportunities for optimization
5. Implement the optimal approach
6. Test with different inputs and edge cases
